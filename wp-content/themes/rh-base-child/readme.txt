=== RH Base Child ===

Template: rh-base

Example child theme. Duplicate this directory for each new client, rename the folder and update style.css headers, then activate in Appearance → Themes.

Parent theme must be installed as rh-base.

== Home hero ==

The front page uses a full-height hero (white frame, Poppins, Font Awesome icons). The default hero photo is copied from assets/images/hero-default.jpg into the Media Library on first page load and linked in Appearance → Customize → Home hero. Replace it there anytime.

Configure phone/social URLs and CTA links under Appearance → Customize → Home hero.

Assign the Primary menu for About / Services / Projects (or rely on the built-in fallback links until menus exist).
